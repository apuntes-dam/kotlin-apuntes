!!! note "Qué es Kotlin"
    Kotlin es un lenguaje **tipado estático, conciso y con null safety**, que se ejecuta en la JVM (y también en Android, web y nativo). Es el lenguaje preferido para Android y es 100 % interoperable con Java.
