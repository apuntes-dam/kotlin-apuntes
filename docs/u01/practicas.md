# Prácticas

## P1. Preparar el entorno
Instala un JDK e IntelliJ IDEA, crea un proyecto Kotlin con Gradle y ejecuta `Hola, Kotlin`.

## P2. Ejercicios progresivos de Kotlin
1. Pide dos números y muestra suma, resta, producto, división y resto.
2. Convierte grados Celsius a Fahrenheit con `Double`.
3. Declara una `const val` con el IVA (0.21) y calcula el precio final de un producto.
4. Lee un número con `toIntOrNull()` y avisa si no es válido.
5. Guarda tres nombres en una `List` y muéstralos con plantillas de texto.

## P3. Proyecto con pruebas
Crea un proyecto Gradle con una función `esPar(n: Int)` y escribe al menos tres pruebas con `kotlin.test`, incluido el caso `0`.

## P4. Git
Sube las prácticas a un repositorio con commits pequeños y mensajes claros. No incluyas claves ni tokens.
