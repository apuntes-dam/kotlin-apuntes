# A2 · Genéricos

Escribir una clase o una función **una sola vez** para que sirva con varios tipos sin perder la seguridad: **tipos parametrizados**, **restricciones** (`T extends ...`), cuándo una lista de enteros es una lista de números y qué pasa con los tipos **al ejecutar** en cada lenguaje.

## Teoría

* [A2.A Tipos parametrizados](t-tipos.md): clases y funciones que sirven para cualquier tipo sin perder la seguridad.
* [A2.B Restricciones y variación](t-restricciones.md): `T extends ...`, comparar, y cuándo una lista de enteros es una lista de números.
* [A2.C Tu colección y qué pasa al ejecutar](t-coleccion.md): una pila genérica, el borrado de tipos y los tipos en ejecución.

## Antes de empezar: qué debes dominar

* Clases, interfaces y herencia (unidades 4 y 5).
* Colecciones: listas y mapas (unidad 3).
* Funciones como valores (unidad A1 de este apartado).
